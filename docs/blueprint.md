# **App Name**: DataLink Forms

## Core Features:

- Multi-User Data Entry: Collect user information including full name, age, address, and live photo using a mobile-responsive data entry form.
- Automatic Location Capture: Capture and store the user's live location when they submit their data entry form.
- Spreadsheet Integration: Connect forms to a set of provided Excel/Google Sheets for data submission.
- Dedicated User Spreadsheets: Save each user's data to their own dedicated spreadsheet, pre-configured by the app owner.

## Style Guidelines:

- Primary color: Professional blue (#1976D2) for a trustworthy feel.
- Secondary color: Success green (#4CAF50) for positive interactions.
- Background color: Light grey (#F5F5F5) to provide a clean interface.
- Text color: Dark grey (#212121) to ensure readability.
- Accent color: Orange (#FF9800) for call-to-action highlights.
- Error color: Red (#F44336) to alert users to issues.
- Use 'Roboto' sans-serif font for form labels and descriptive text, for clean readability. Note: currently only Google Fonts are supported.
- Employ a card-based form layout with clearly defined sections and 16px spacing to optimize mobile-responsive design. Implement progress indicators.
